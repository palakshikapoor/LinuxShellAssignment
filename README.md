# LinuxShellAssignment

## Project Overview
This project provides practical experience with Linux, shell commands, and scripting. It focuses on file management, process monitoring, networking, and automation tasks. The project also demonstrates using GitHub for version control and hosting code.

---

## Instructions for Running the Scripts
Open WSL (Ubuntu).  

Make scripts executable (if needed):

bash
Copy code
chmod +x backup.sh cpumem.sh download.sh
Run the scripts as described below.

Script Descriptions
1. backup.sh
Purpose: Copies a specified directory to a backup folder with a timestamp.

Usage:

bash
Copy code
./backup.sh /source/directory /backup/directory
2. cpumem.sh
Purpose: Logs CPU and memory usage at regular intervals.

Usage:

bash
Copy code
./cpumem.sh
3. download.sh
Purpose: Downloads a file from the internet to a predefined directory.

Usage:

bash
Copy code
./download.sh <URL> /destination/directory
